# Personal Portfolio

A full-stack personal portfolio website built to showcase my projects, skills, and experience.

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## Project Structure

```
Portfolio/
├── portfolio-frontend/
├── portfolio-backend/
├── README.md
└── .gitignore
```

## Features

* Responsive UI
* Project showcase
* Contact form
* Backend API
* MongoDB integration

## Installation

### Clone the repository

```bash
git clone <repository-url>
cd Portfolio
```

### Frontend

```bash
cd portfolio-frontend
npm install
npm start
```

### Backend

```bash
cd portfolio-backend
npm install
npm run dev
```
